# Merkbestanden voor de Dees-website

Zet hieronder de echte huisstijl-bestanden neer. Zodra alles erin staat, bouw ik
de website meteen merk-getrouw (echte fonts, logo, kleuren en sfeer).

Niets is verplicht — lever aan wat je hebt. Ik vul de rest netjes in met het
kleurenpalet uit de prompt en tijdelijke fonts, en swap het later moeiteloos om.

## Waar zet ik wat?

| Map                | Wat erin | Formaat (voorkeur) |
|--------------------|----------|--------------------|
| `brand/brandbook/` | Het brandbook | PDF |
| `brand/logo/`      | Logo('s): volledig logo + eventueel losse merk/icoon-versie, en varianten voor lichte én donkere achtergrond | SVG (voorkeur), anders PNG met transparante achtergrond |
| `brand/fonts/`     | De merk-fonts (kop-font + body-font + eventueel handgeschreven font) | `.woff2` (voorkeur voor web), anders `.otf` / `.ttf` |
| `brand/images/`    | Foto's / illustraties / handgetekende elementen die je op de site wilt | JPG/PNG/SVG |
| `brand/moodboard/` | Het moodboard uit de prompt (als referentie voor mij) | PNG/JPG/PDF |

## Handig om te weten

- **Fonts:** als je de fonts als `.otf`/`.ttf` aanlevert converteer ik ze zelf
  naar web-formaat. Laat wel even weten of de licentie webgebruik toestaat.
- **Logo:** SVG is ideaal (blijft scherp op elk formaat). Heb je alleen een PNG,
  lever dan de grootst mogelijke versie aan.
- **Kleuren:** die heb ik al uit de prompt —
  lichtblauw `#AFC8FF`, bordeaux `#7A1F2E`, crème `#F1EBC8`, accent-rood `#FF2A00`,
  zwart voor tekst. Staan er in het brandbook andere/aanvullende kleuren of exacte
  waarden, dan neem ik die over.
- **Favicon:** heb je een klein merk-icoon? Zet 'm in `brand/logo/`, dan maak ik
  de favicon.

Klaar met droppen? Laat het me weten ("de bestanden staan erin") en ik ga bouwen.
